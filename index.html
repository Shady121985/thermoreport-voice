1. Datos generales

El área se propone para cada equipo; puedes cambiarla individualmente.

2. Dictar un equipo

Dicta la ficha completa de corrido. Usa etiquetas como Área, Equipo, Identificación, Capacidad, Prioridad y Observaciones para distribuir el texto.

Ejemplo: “Área subestación, equipo transformador TR cero siete, identificación lado primario H uno H dos, capacidad dos mil kVA, estado encendido, prioridad dos, observaciones apartarrayos con calentamiento anormal”.
Listo para capturar. El reconocimiento de voz depende del navegador y puede requerir internet.

3. Equipos capturados 0

Aún no hay equipos guardados.

Este botón elimina todos los puntos guardados de esta lista en el dispositivo. Exporta a Excel o guarda un respaldo JSON antes de usarlo.

Los datos se guardan en este dispositivo mientras no borres los datos del navegador. Exporta respaldos periódicamente. El archivo conserva las columnas A–H de Hoja1; las columnas auxiliares I–J no se generan porque son fórmulas auxiliares del archivo de origen.
